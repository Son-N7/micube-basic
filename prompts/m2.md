# 2번 모듈 실습 프롬프트 — Claude Code 구조와 에이전틱 루프: 실습 환경 점검

- 시작 지점: 태그 `m2-start`.
- 코드 블록을 그대로 복사해 붙여넣습니다. **[터미널]** 표시는 터미널에, 나머지는 Claude Code 입력창에 입력합니다.
- Windows는 Git Bash에서 입력합니다.

## 1. 실습 환경 점검

README의 "수업 전 준비"를 마쳤다면 시작 태그에서 실습 브랜치를 만들고 점검합니다.

**[터미널]**
```
git switch -c practice/m2 m2-start
./gradlew build
node -v
cp .env.example .env
./gradlew dbReset
node scripts/db.mjs --env dev "SELECT TOP 3 lot_no, status FROM stock_lot WITH (NOLOCK)"
claude --version
```

| 확인 | 기대 결과 |
|---|---|
| `./gradlew build` | `BUILD SUCCESSFUL` |
| `node -v` | `v20` 이상 |
| `./gradlew dbReset` | "개발 DB 준비", "운영 흉내 DB 준비" 두 줄 |
| `node scripts/db.mjs ...` | 로트 3행과 `(3행, DB 실행 … ms)` |
| `claude --version` | 버전 번호 |

## 2. Claude Code 실행과 컨텍스트 확인

**[터미널]**


처음 실행하면 이 폴더를 신뢰할지 묻습니다. 승인합니다.
