### STEP 05. 구조화: 항상 올라오는 것과 필요할 때만 올라오는 것 나누기

루트 CLAUDE.md는 매 턴 컨텍스트에 들어갑니다. 길수록 매번 토큰을 쓰고 핵심이 묻힙니다. 루트에는 모든 작업에 필요한 것만 두고, 특정 파일에만 필요한 규칙은 그 파일을 다룰 때만 올라오게 나눕니다.

① 루트 CLAUDE.md를 짧은 '헌법'으로 다듬기

```
방금 만든 CLAUDE.md 를 다듬어 줘. 매 턴 자동으로 컨텍스트에 들어가는 파일이라 짧고 핵심만 있어야 해.
아래만 남기고 나머지 군더더기(/init 이 넣은 영어 머리말 포함)는 빼 줘.
- 프로젝트 한 줄 소개 (식품 온라인몰 재고 백오피스)
- 기술 스택 (Java 25, Spring Boot 4.1, MyBatis, H2 MSSQL 호환 모드, Gradle)
- 패키지 구조 (기능 product·stock 아래 api / application / domain / mapper, SQL은 resources/mapper 의 XML)
- 핵심 규칙: 의존 방향(api → application → domain·mapper, 다른 기능 데이터는 그 기능의 Service로),
  업무 오류는 ErrorCode + BusinessException, 응답은 ApiResponse, 현재 시각은 주입받은 Clock, SQL은 MSSQL 문법,
  운영 DB는 조회만, 완료 전에 ./gradlew test 와 checkstyleMain 통과, 요청 범위 밖 리팩터링 금지
- 빌드·테스트·실행 명령과 DB 도구 명령(dbReset, scripts/db.mjs, scripts/render-sql.mjs)
- 답변과 문서는 한국어로
```

② 매퍼 규칙은 `.claude/rules/`로 분리하고 `paths` 걸기

매퍼 규칙은 매퍼를 만질 때만 필요합니다. `paths`를 걸면 그 파일을 다룰 때만 올라옵니다.

```
매퍼에만 적용되는 규칙을 .claude/rules/mybatis.md 로 분리해 줘.
frontmatter 에 paths 를 걸어서 매퍼 XML(src/main/resources/mapper/**)과 매퍼 인터페이스(src/main/java/**/mapper/**)를 만질 때만 로드되게 해 줘.
내용은 docs/conventions/mybatis-convention.md 의 C1~C5 를 한 줄씩 요약하고, 원문 파일 위치를 적어 줘.
```

③ 테스트 안내는 하위 폴더 `CLAUDE.md`로

```
테스트 작성 안내를 src/test/CLAUDE.md 로 만들어 줘. 테스트 파일을 다룰 때만 올라오게 하려는 거야.
기존 테스트에서 확인되는 것만 적어 줘: 통합 테스트 어노테이션, 테스트 데이터 만드는 법(로트 번호 접두어 포함), 현재 시각 고정, 요청 사용자 헤더.
테스트에서는 쓰지 않고 support 코드에만 있는 것은 그렇다고 표시해 줘.
```

④ 항상 지킬 규칙은 `paths` 없이 (②와 비교)

커밋 규칙처럼 어떤 파일을 다루든 지켜야 하는 규칙은 `paths` 없이 둡니다. 세션 시작 때부터 항상 올라옵니다.

```
커밋 메시지 규칙은 어느 파일을 만지든 항상 지켜야 하니 .claude/rules/git.md 로 만들되, paths 는 걸지 말고 항상 로드되게 해 줘. 내용은:
- 형식: <type>: <요약 50자 이내> / 빈 줄 / 본문(무엇을 왜). type 은 feat·fix·refactor·test·docs·chore
- 한 커밋에는 한 가지 변경만 담고, 커밋마다 테스트가 통과해야 한다
- Co-Authored-By 같은 트레일러는 붙이지 않는다
마지막으로 루트 CLAUDE.md 끝에 세부 규칙과 문서의 위치 표(mybatis.md, git.md, src/test/CLAUDE.md, docs 의 사내 문서)를 넣어 줘.
```

**[터미널]** 줄 수는 Claude의 답 대신 직접 확인합니다.
```
wc -l CLAUDE.md .claude/rules/*.md src/test/CLAUDE.md
```

끝난 뒤 확인
- 루트 `CLAUDE.md`가 짧고(60줄 안팎), 세부 규칙은 위치만 적혀 있다
- `.claude/rules/mybatis.md` 맨 위에 `paths`가 있다 (매퍼를 다룰 때만 올라옴)
- `.claude/rules/git.md`에는 `paths`가 없다 (항상 올라옴)
- `src/test/CLAUDE.md`가 있다

⑤ (선택, 시간이 남으면) API 규칙도 `paths`로 분리하기

②와 같은 방식을 API 코드에 적용해 봅니다.

```
API 작성 규칙을 .claude/rules/api.md 로 분리해 줘.
frontmatter 에 paths 를 걸어서 API 코드(src/main/java/**/api/**)를 만질 때만 로드되게 해 줘.
기존 출고 API(LotController.ship)에서 확인되는 것만 적어 줘: 역할 확인, 요청 검증, 응답 형식, 오류 코드.
루트 CLAUDE.md 의 위치 표에도 한 줄 추가해 줘.
```

답은 4번 모듈 시작 태그에 있습니다. 내 결과와 비교합니다 (**[터미널]**).
