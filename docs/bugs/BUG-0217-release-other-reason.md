# BUG-0217 고객 클레임 보류를 풀었더니 품질 보류까지 풀림

| 항목 | 내용 |
|---|---|
| 제보 | 품질팀 최수진 / 2026-09-25 16:40 |
| 심각도 | 높음 (품질 검사 중인 로트가 판매 가능 재고에 잡혀 출고될 수 있음) |
| 대상 | 판매 보류 해제 API `POST /api/lots/{lotNo}/holds/release` |

## 제보 내용

`LT-260924-0031`(닭가슴살 샐러드)에 품질 보류(QUALITY, 드레싱 변질 의심 검사 중)와 고객 클레임 보류(CLAIM)를 함께 걸어 두었습니다.
고객 클레임 조사가 끝나서 CLAIM 보류만 해제했는데, 로트가 판매 가능(AVAILABLE)으로 바뀌어 물류팀 출고 목록에 올라왔습니다.
품질 검사는 아직 끝나지 않았습니다.

## 재현 절차

1. QC가 판매 가능 로트에 `QUALITY` 보류 등록 → HOLD
2. 같은 로트에 `CLAIM` 보류 등록 → HOLD (활성 보류 2건)
3. `CLAIM` 보류 해제 요청 `{"reasonCode": "CLAIM"}`

| | 기대 | 실제 |
|---|---|---|
| 로트 상태 | HOLD | AVAILABLE |
| QUALITY 활성 보류 | 1건 | 0건 (해제됨, 해제 코멘트도 CLAIM 해제 때 것) |

## 참고

- 업무 규칙: `docs/specs/release-hold.md` 처리 3·4, 확인 시나리오 2
- 임시 조치: 해당 로트는 품질팀이 다시 보류 요청함 (DB 직접 등록)
